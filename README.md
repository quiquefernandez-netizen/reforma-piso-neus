# Casa Neus

Aplicación web móvil para organizar la reforma, las compras y la mudanza del piso de Neus.

## Funciones

- Cronograma e hitos editables.
- Checklist completo por fases y habitaciones.
- Planificador “¿Qué hacemos hoy?” según el tiempo disponible.
- Presupuesto previsto y gasto real.
- Guía de limpieza profunda.
- Notas, fotos y copia de seguridad.
- Guardado local, instalación como PWA y funcionamiento sin conexión.

## Uso

La aplicación no necesita servidor ni proceso de compilación. Puede abrirse desde GitHub Pages y añadirse a la pantalla de inicio del móvil. Los datos personales se guardan únicamente en el navegador del dispositivo.

## Publicación

El sitio está preparado para publicarse desde la raíz de la rama `main` mediante GitHub Pages.
